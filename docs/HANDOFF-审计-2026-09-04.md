### P2 · 代码规范与仓库卫生

#### 3.11 `refresh.py` 函数遮蔽（真实 bug）
```python
# 第 12 行
from cloud.local_sync import run_logging, git_pull, sync_repo_intel, translate_local
# 第 14-17 行 —— 同名局部定义覆盖了 import
def git_pull():
    r = subprocess.run(["git", "pull", "origin", "master"], ...)
```
- 后果：第 272 行调用的 `git_pull()` 执行的是**本地裸 `git pull` 版**，`cloud/local_sync.py` 里那版（带重试/日志/错误处理）成为死代码
