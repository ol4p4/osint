## 1. 验收标准

### 1.1 延迟（拆成两项可诊断指标）

```
lag_fetch   = fetched_at − published_at               # 采集延迟
lag_publish = dashboard_data.generated_at − fetched_at # 发布延迟
lag_total   = lag_fetch + lag_publish
```

| 分档 | P95(lag_fetch) | P95(lag_publish) | P95(lag_total) |
|---|---|---|---|
| 国内源（`scope≠ci`） | ≤ 20 min | ≤ 10 min | **≤ 30 min** |
| 国外源（`scope=ci`） | ≤ 4 h | ≤ 0.5 h | **≤ 4.5 h** |

- **P95 算法**：样本升序，`index = ceil(0.95 × n)` 取该位值（nearest-rank）
- **样本量**：每档 ≥ 30 条有效样本；**观察窗口 ≥ 48h**（覆盖国内 ≥3 个调度周期、国外 ≥2 个周期）
- **采样排除规则（v2 新增）**：只统计 schedule 触发的 run。push 触发的 run 无轮次等待时间，会拉低 P95——按 auto commit 时间锚点区分，落在整点 ±5min 内开始的为 schedule（GitHub schedule 有延迟，实测 auto commit 从不落在整点后半小时内，需以 commit 落地时刻反推 run 开始时刻）

### 1.2 翻译覆盖率 + 源级可达率（v2 新增后者）

**应翻译条目（分母）** = `scope == "ci"` 或 `language != "zh"`，且状态 ≠ `skipped_zh`，**且其源实际产出条目**（见可达率）

⚠️ 禁止按 `category` 区分国内外：`data/refresh.py:27-42` 的 `_norm_cat()` 把国内"金融市场"与国外 `finance` 都归一为 `finance` → 必须用 `source_name` 或 `scope`

| 指标 | 阈值 |
|---|---|
| **源级可达率（v2 新增 P0）**：配置的 ci 源中，观察窗口内实际产出 ≥1 条的占比 | **≥ 90%** |
| 翻译覆盖率 = `cn_title` 非空且 `translate_status=="ok"` / 应翻译条目 | **≥ 99%**（滚动 7 天窗口） |
| 稳态积压 `translation_state.summary.pending` | **== 0** |
| `give_up` 条目 | ≤ 1% 且逐条告警 |

> **为什么加可达率**：2026-09-04 CI 实测新辅助源 4/10 通（Bloomberg×2=37 条、DW×2=14 条通；Reuters×2/CNN×2/AP×2 不通）。CNN feed 疑似已死、Reuters 路由需 cookie、AP 上游偶拦数据中心 IP。**源采不到 → 不产生条目 → 不进覆盖率分母 → 覆盖率假达标**。可达率是防止这种假达标的关键指标。
> **去留决策（2026-09-04 已定，commit 3395c9e / b2b7fdb）**：CNN×2 移除（feed 疑死）；Reuters×2 移除（cookie 方案实测不可靠，用户决策放弃修复）；AP×2 保留观察（路由已就位，上游偶拦交 schedule 自然重试）。ci 源 33→29，geopolitics 由 AP+CNBC-World 覆盖，finance 由 Bloomberg+CNBC×3+MarketWatch×3 覆盖。若后续某 ci 源连续 2 周可达率 0%，按同样流程移除。

**存量处理**：1400+ 条历史积压走**分层滚动摘要**（§5），逐条翻译只对**当日新增 + 近 7 天**严格考核。

### 1.3 原文兜底三条规则（可判定形式）

| # | 规则 | 断言 |
|---|---|---|
| ① | 徽章显式 EN，不伪装 CN | `if (!i.cn_title && i.language !== "zh") assert badge !== "CN"` |
| ② | 正文永不空白 | `cn_summary` 空时回退 `summary \|\| content_preview.slice(0,200) \|\| title`，渲染 `item-body` 非空 |
| ③ | 失败留队 + 计数 | 未译条目 `_translate_status="failed"` 留队；连续 3 轮失败转 `give_up` 且 `give_up_count += 1` 告警 |

现状：① 已满足（`gen_dashboard.py:833` 未译显示 EN）；**② 未满足**（正文 `esc(i.cn_summary||"")` 无 fallback，未翻译时正文空白）；③ 完全缺失。
